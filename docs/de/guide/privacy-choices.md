# Datenschutzoptionen

NueZip ist eine vollständig offline arbeitende Anwendung. Da all Ihre Daten auf Ihrem Gerät verbleiben, sammeln, verkaufen oder teilen wir keine persönlichen Informationen.

## Daten, die wir lokal vorhalten

NueZip speichert alle Daten lokal auf Ihrem Mac:
- App-Einstellungen und -Konfiguration
- Liste zuletzt geöffneter Dateien
- Debug-Protokolle (falls aktiviert)
- Im Schlüsselbund gespeicherte Passwörter (falls Sie sie zu speichern wählen)

Keine dieser Daten wird auf einen Server hochgeladen.

## Ihre Rechte

Da NueZip keine persönlichen Daten auf unseren Servern sammelt oder speichert, gibt es keine persönlichen Daten, auf die wir zugreifen, die wir löschen oder übertragen könnten. Alle Ihre Daten können direkt in der App verwaltet oder durch Entfernen des Container-Ordners der App gelöscht werden:

```bash
rm -rf ~/Library/Containers/com.w3cub.nuezip
```

## Kein Verkauf

NueZip verkauft keine persönlichen Informationen. Wir verwenden keine Analysen, Werbung oder Tracking-Dienste von Drittanbietern irgendeiner Art.
