# Nutzungsbedingungen

Diese Bedingungen regeln Ihre Nutzung von NueZip. Durch Herunterladen, Installieren oder Nutzen von NueZip stimmen Sie diesen Bedingungen zu. Wenn Sie nicht zustimmen, nutzen Sie die Anwendung nicht.

## Lizenz und Nutzung

NueZip wird unter den Lizenzbedingungen bereitgestellt, die jeder Version beiliegen. Ihnen wird eine begrenzte, nicht-exklusive, nicht-übertragbare Lizenz zur Nutzung der Anwendung auf Ihrem Mac gemäß den Lizenzbedingungen eingeräumt.

## Nur-lokal-Betrieb

NueZip ist eine vollständig offline arbeitende Anwendung. Alle Archivvorgänge werden lokal auf Ihrem Gerät ausgeführt. Es werden keine Dateien, Metadaten oder persönlichen Daten an externe Server übertragen.

## Käufe

Eine Vollversionslizenz ist über einen einmaligen Kauf im Mac App Store erhältlich. Alle Käufe werden von Apple abgewickelt. NueZip verarbeitet keine Zahlungsinformationen. Die Wiederherstellung von Käufen wird bei Neuinstallationen unterstützt.

## Benutzerpflichten

- Nutzen Sie NueZip rechtmäßig und in Übereinstimmung mit geltenden Regeln.
- Versuchen Sie nicht, die App entgegen der Lizenz zu dekompilieren, reversezukonstruieren oder zu modifizieren.
- Nutzen Sie NueZip nicht, um Urheberrechtsschutz oder DRM auf Archiven zu umgehen.
