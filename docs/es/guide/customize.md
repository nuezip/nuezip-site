# Personalización

Haz que NueZip sea verdaderamente tuyo personalizando tu experiencia de gestión de archivos. Esta guía cubre todo lo que puedes personalizar.

## Preferencias generales

Abre **NueZip → Ajustes** (o pulsa `Cmd+,`) para acceder a todas las opciones de personalización.

### Apariencia
- **Tema**: Elige entre Claro, Oscuro o Sistema (sigue la apariencia de macOS)
- **Estilo de icono**: Define un icono de barra de menú monocromo o a todo color
- **Idioma**: Selecciona entre los idiomas compatibles (English, 中文, 日本語, 한국어, y más)

## Valores predeterminados de compresión

Define tus valores predeterminados de compresión preferidos:

| Ajuste | Opciones | Descripción |
|---------|---------|-------------|
| **Formato predeterminado** | ZIP, 7z, TAR, GZIP, BZIP2, XZ | Formato de archivo para compresión rápida |
| **Nivel de compresión** | Store, Fast, Normal, Maximum, Ultra | Compensación entre velocidad y relación |
| **Cifrado** | None, AES-128, AES-256 | Cifrado predeterminado para archivos ZIP/7z |
| **Tamaño de volumen** | Personalizado (MB) | Tamaño de división predeterminado para archivos multi-volumen |

### Configuración de ejemplo

Para uso diario:
- **Formato**: ZIP
- **Nivel**: Normal
- **Cifrado**: AES-256 (para archivos sensibles)
- **Volumen**: Desactivado

Para archivar:
- **Formato**: 7-Zip
- **Nivel**: Ultra
- **Cifrado**: AES-256
- **Volumen**: 4,7 GB (para caber en DVD)

## Preferencias de extracción

Personaliza el comportamiento de extracción:

- **Extraer a subcarpeta por defecto**: Crea automáticamente una carpeta con nombre al extraer
- **Abrir carpeta tras la extracción**: Muestra los contenidos extraídos en Finder
- **Comportamiento de sobrescritura**: Preguntar, Sobrescribir siempre o Omitir archivos existentes
- **Conservar fechas de archivos**: Mantiene las marcas de tiempo originales del archivo

## Extensión de Finder

Gestiona la integración del menú contextual de Finder:

- **Habilitar/Deshabilitar**: Activa o desactiva los elementos del menú con clic derecho
- **Acciones rápidas**: Elige qué acciones aparecen en el menú contextual
  - Extraer aquí
  - Extraer a carpeta
  - Comprimir a ZIP
  - Comprimir con opciones

Gestiona esto en: **Configuración del sistema → Privacidad y seguridad → Extensiones → Extensiones de Finder**

## Icono de la barra de menú (bandeja)

Personaliza el panel de la barra de menú:

- **Mostrar en la barra de menú**: Activa/desactiva el icono de la bandeja
- **Cerrar panel automáticamente**: Cierra el panel de desecho tras la extracción
- **Archivos recientes**: Número de elementos recientes a mostrar
- **Salir al cerrar**: Si la app permanece en segundo plano

## Notificaciones

- **Mostrar avisos de finalización**: Avisa cuando terminan las operaciones largas
- **Mostrar avisos de error**: Muestra notificaciones para operaciones fallidas
- **Sonido**: Reproduce un sonido al completar las operaciones

## Ajustes generales

Accede a estos en **Ajustes → General**:

- **Idioma**: Cambia entre English, 中文, 日本語, y más
- **Iniciar al iniciar sesión**: NueZip se inicia automáticamente al iniciar sesión
- **Tema**: Modo claro u oscuro (sigue al sistema por defecto)
- **Icono de barra de menú**: Muestra u oculta el icono de la barra de menú

## Consejos

- Define tus valores predeterminados de compresión favoritos una vez para agilizar el archivado diario
- Habilita "Iniciar al iniciar sesión" para que NueZip esté siempre a un clic de distancia
- Usa la extensión de Finder para el flujo de trabajo de extracción/compresión más rápido
- Revisa el acceso a carpetas periódicamente en Configuración del sistema para mantener todo ordenado
