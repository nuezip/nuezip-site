# Politique de confidentialité

NueZip est conçu comme une application entièrement hors ligne d'abord. Votre confidentialité est notre priorité.

## Conception locale uniquement

- Toutes les opérations d'archives — compression, extraction, conversion, chiffrement — s'exécutent entièrement sur votre Mac.
- NueZip ne téléverse pas vos fichiers ou données vers des serveurs externes.
- Aucun compte ou inscription n'est requis pour utiliser l'application.
- Aucune connexion internet n'est requise pour le fonctionnement normal.

## Ce que nous ne collectons pas

- Nous ne collectons pas vos fichiers, documents ou contenus d'archive.
- Nous ne suivons pas votre activité, votre comportement de navigation ou vos habitudes d'utilisation.
- Nous n'envoyons aucune métadonnée de fichier ou information personnelle vers des serveurs externes.
- Nous n'incluons aucune analyse tierce, publicité ou SDK de suivi.
- Nous n'avons aucun système de télémétrie.

## Quelles données sont stockées localement

Les données suivantes sont stockées uniquement sur votre appareil :
- **Réglages de l'application** : Thème, préférence de langue, préférences de compression
- **Clé de licence** : Si achetée (stockée en toute sécurité dans le trousseau local)
- **Liste des fichiers récents** : Archives récemment ouvertes pour un accès rapide
- **Enregistrements de mots de passe** : Stockés dans votre trousseau local si vous choisissez de les enregistrer
- **Journaux** : Journaux de débogage pour le dépannage (peuvent être supprimés à tout moment)

## Permissions utilisées par l'application

- **Fichiers et dossiers** : Requis pour lire les fichiers d'archive et extraire les contenus.
- **Extension Finder** : Optionnelle, ajoute des éléments de menu contextuel au clic droit dans Finder.
- **Notifications** : Optionnelles, pour les alertes de fin sur les tâches de longue durée.

Vous pouvez gérer ces permissions dans **Réglages système → Confidentialité et sécurité** à tout moment.

## Achats intégrés / Licence

Les achats de licence sont traités par Apple via le Mac App Store. NueZip ne reçoit ni ne stocke vos informations de paiement. Les reçus de licence sont stockés localement pour vérifier la propriété.

## Services tiers

NueZip n'inclut aucune analyse tierce, publicité ou service de suivi. L'application est entièrement autonome.

## Demandes de confidentialité

Puisque NueZip stocke toutes les données localement sur votre appareil, nous ne détenons aucune donnée personnelle sur nos serveurs. Si vous avez des questions sur la confidentialité, veuillez nous contacter.

## Contact

Pour les questions de confidentialité, ouvrez un problème sur [GitHub Issues](https://github.com/nuezip/nuezip/issues) ou envoyez-nous un e-mail.
