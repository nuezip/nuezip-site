# コントリビューション

NueZip の改善に向けたコントリビューションを歓迎します！ バグの修正、機能の追加、翻訳、ドキュメントの改善など、どのような形でのご協力も感謝いたします。

## コントリビューションの方法

### バグ報告
- まず既存の [issues](https://github.com/nuezip/nuezip/issues) を確認してください
- macOS のバージョン、NueZip のバージョン、再現手順を記載してください
- 可能であれば、サンプルのアーカイブを添付してください（最小サイズで）

### 機能リクエスト
- 機能とそのユースケースを説明してください
- それが NueZip ユーザーにどのように役立つかを説明してください
- オフライン優先、ネイティブ macOS という理念と合致するか確認してください

### 翻訳
- NueZip は複数の言語をサポートしています。macOS アプリについては、既存の翻訳は `NueZip/Resources/i18n/` を参照してください。
- このドキュメントサイトについては、`docs/` 配下の markdown を翻訳してください。各言語は専用のロケールフォルダに配置されます（例：`docs/zh-CN/`、`docs/es/`）。
- ブランド名およびフォーマット名（NueZip、macOS、ZIP、RAR、7-Zip、Finder、App Store、AES-256）は原文のまま保持してください。

### コードのコントリビューション
- このプロジェクトは **Swift 6 + SwiftUI** で書かれています
- リポジトリをフォークしてプルリクエストを送信してください
- コードベースで使用されているクリーンアーキテクチャのパターンに従ってください

## はじめに

### 前提条件
- Node.js 18 以降（サイト用）
- pnpm パッケージマネージャー（サイト用）
- Xcode 16+（アプリ開発用）
- macOS 14 Sonoma+

### 開発環境のセットアップ

1. **リポジトリをフォーク** する（GitHub 上で）
2. **フォークをクローン** する：
   ```bash
   git clone https://github.com/nuezip/nuezip.git
   cd nuezip-site
   ```
3. **依存関係をインストール** する：
   ```bash
   pnpm install
   ```
4. **開発サーバーを起動** する：
   ```bash
   pnpm docs:dev
   ```
5. ブラウザで `http://localhost:5173` を **開く**

### 変更を加える

1. 変更用の新しいブランチを作成する：
   ```bash
   git checkout -b feature/your-feature-name
   ```
2. `docs/` 内のドキュメントファイルを変更する
3. サイトをビルドして変更をテストする：
   ```bash
   pnpm docs:build
   ```
4. 変更をコミットする：
   ```bash
   git add .
   git commit -m "Description of your changes"
   ```

### 変更の送信

1. **ブランチをフォークにプッシュ** する：
   ```bash
   git push origin feature/your-feature-name
   ```
2. GitHub で **プルリクエストを作成** する
3. **レビューを待ち**、フィードバックに対応する

## ガイドライン

### 文体
- 明確で簡潔な言葉を使う
- 可能な限り能動態で書く
- 思いやりがあり、歓迎する姿勢を保つ
- 一貫したフォーマットを使う
- 役立つ場合はスクリーンショットを含める

### ファイル構造
- ドキュメントページは `docs/` に配置する
- ガイドは `docs/guide/` に配置する
- ファイル名は小文字とハイフンを使用する：`my-new-guide.md`
- フロントマターは必須ではありませんが、メタデータに使用できます

### リンク
- 内部ドキュメントには相対リンクを使用する
- 役立つ場合は外部リソースへのリンクを含める
- すべてのリンクが機能することを確認する

### 画像とアセット
- 画像は `docs/public/` またはサブディレクトリに配置する
- 説明的なファイル名を使用する
- 画像はウェブ向けに最適化する（500KB 未満推奨）
