# カスタマイズ

アーカイブ管理の体験をカスタマイズして、NueZip を真に自分好みにしてください。このガイドでは、カスタマイズできるすべての項目を説明します。

## 一般設定

**NueZip → 設定**（または `Cmd+,` を押す）を開くと、すべてのカスタマイズオプションにアクセスできます。

### 外観
- **テーマ**: ライト、ダーク、またはシステム（macOS の外観に追従）から選択
- **アイコンスタイル**: モノクロまたはフルカラーのメニューバーアイコンを設定
- **言語**: 対応言語から選択（English、中文、日本語、한국어、など）

## 圧縮のデフォルト

お好みの圧縮デフォルトを設定します：

| 設定 | オプション | 説明 |
|---------|---------|-------------|
| **デフォルトフォーマット** | ZIP、7z、TAR、GZIP、BZIP2、XZ | クイック圧縮用のアーカイブフォーマット |
| **圧縮レベル** | Store、Fast、Normal、Maximum、Ultra | 速度と圧縮率のトレードオフ |
| **暗号化** | None、AES-128、AES-256 | ZIP/7z アーカイブのデフォルト暗号化 |
| **ボリュームサイズ** | カスタム（MB） | マルチボリュームアーカイブのデフォルト分割サイズ |

### 設定例

日常的な使用の場合：
- **フォーマット**: ZIP
- **レベル**: Normal
- **暗号化**: AES-256（機密ファイル用）
- **ボリューム**: オフ

アーカイブ保存の場合：
- **フォーマット**: 7-Zip
- **レベル**: Ultra
- **暗号化**: AES-256
- **ボリューム**: 4.7 GB（DVD に収めるため）

## 展開設定

展開の動作をカスタマイズします：

- **デフォルトでサブフォルダに展開**: 展開時に名前付きフォルダを自動作成する
- **展開後にフォルダを開く**: 展開された内容を Finder で表示する
- **上書き動作**: 確認する、常に上書きする、または既存ファイルをスキップする
- **ファイルの日付を保持**: アーカイブから元のタイムスタンプを保持する

## Finder 機能拡張

Finder のコンテキストメニュー連携を管理します：

- **有効／無効**: 右クリックメニューの項目をオンまたはオフにする
- **クイックアクション**: コンテキストメニューに表示するアクションを選択する
  - ここに展開
  - フォルダに展開
  - ZIP に圧縮
  - オプションを指定して圧縮

これらの管理は以下で行います：**システム設定 → プライバシーとセキュリティ → 機能拡張 → Finder 機能拡張**

## メニューバー（トレイ）アイコン

メニューバーのドロップパネルをカスタマイズします：

- **メニューバーに表示**: トレイアイコンを有効／無効にする
- **パネルを自動的に閉じる**: 展開後にドロップパネルを閉じる
- **最近のアーカイブ**: 表示する最近の項目の数
- **閉じるときに終了**: アプリがバックグラウンドに残るかどうか

## 通知

- **完了アラートを表示**: 長時間の操作が終了したときに通知する
- **エラーアラートを表示**: 操作が失敗したときに通知を表示する
- **サウンド**: 操作完了時にサウンドを再生する

## 一般設定

以下は **設定 → 一般** でアクセスします：

- **言語**: English、中文、日本語、などを切り替える
- **ログイン時の起動**: ログイン時に NueZip が自動的に起動する
- **テーマ**: ライトまたはダークモード（デフォルトはシステムに追従）
- **メニューバーアイコン**: メニューバーアイコンを表示または非表示にする

## ヒント

- お気に入りの圧縮デフォルトを一度設定し、日常のアーカイブ作業を高速化する
- 「ログイン時の起動」を有効にして、NueZip を常にワンクリックで呼び出せるようにする
- Finder 機能拡張を使用して、最速の展開／圧縮ワークフローを実現する
- 定期的にシステム設定でフォルダアクセスを見直し、整理された状態を保つ
