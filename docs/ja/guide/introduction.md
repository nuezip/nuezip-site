# はじめに

## NueZip について

NueZip は、速度、信頼性、使いやすさを追求して設計された、macOS 向けのプロフェッショナルなアーカイブマネージャーです。ファイルの圧縮、アーカイブの展開、フォーマットの変換、パスワード保護されたアーカイブの管理など、NueZip はすべてをネイティブな macOS 体験で処理します。

Swift 6 と SwiftUI で構築された NueZip は、Apple Silicon と macOS の技術を最大限に活用し、高速で軽量かつ安全なアーカイブ管理ツールを提供します。

## 主な機能

### 📦 **マルチフォーマット対応**
NueZip はすべての主要なアーカイブフォーマットをサポートします：
- **RAR** — マルチボリューム対応の読み取り専用
- **ZIP** — AES 暗号化を備えた汎用圧縮
- **7-Zip** — LZMA2 による高圧縮率
- **TAR** — オプションの GZIP/BZIP2 を伴うアーカイブのバンドル
- **GZIP / BZIP2** — 単独の圧縮フォーマット

### ⚡ **高速な展開**
デュアルエンジンアーキテクチャが各フォーマットに最適なバックエンドを選択し、可能な限り高速な展開速度を実現します。

### 🔐 **パスワード保護と暗号化**
業界標準の暗号化を用いて、パスワードで保護されたアーカイブを作成できます。内蔵のパスワードマネージャーが資格情報をローカルのキーチェーンに安全に保存します。

### 📋 **バッチ操作**
複数のファイルを一度に処理できます：
- **バッチ圧縮** — 複数の項目を個別のアーカイブに圧縮する
- **バッチ展開** — 複数のアーカイブを同時に展開する
- **バッチ変換** — フォーマット間でアーカイブを一括変換する
- **バッチ暗号化** — 複数のアーカイブにパスワード保護を適用する

### 🛠️ **高度なツール**
- **アーカイブ修復** — 破損した RAR および ZIP アーカイブを修復する
- **フォーマット変換** — 対応する任意のフォーマット間で変換する
- **パフォーマンスベンチマーク** — 圧縮速度と評価をテストする
- **アーカイブ検索** — アーカイブ内のファイルを名前で検索する
- **ファイル情報ビューア** — アーカイブ項目の詳細なメタデータを表示する
- **ボリューム/分割対応** — マルチボリュームアーカイブを作成する

### 🖥️ **ネイティブな macOS 体験**
- **Swift 6 + SwiftUI** — モダンで応答性の高いインターフェイス
- **Apple Silicon ネイティブ** — M シリーズチップに最適化
- **Finder 統合** — 右クリックのコンテキストメニュー拡張
- **ドラッグ＆ドロップ** — メニューバーのドロップパネルからのクイックアクセス
- **最小限のリソース使用** — 軽量なバックグラウンド動作

## システム要件

- **オペレーティングシステム**: macOS 14 Sonoma 以降
- **CPU**: Apple Silicon（M シリーズ）または Intel（64-bit）
- **メモリ**: 最小 4GB RAM、推奨 8GB
- **ストレージ**: インストールに約 50 MB

## 対応言語

NueZip は英語、中国語（簡体字）、中国語（繁体字）、日本語、韓国語、および他の多くの言語をサポートしています。
