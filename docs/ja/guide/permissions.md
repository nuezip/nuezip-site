# macOS の権限

NueZip は、最良の体験を提供するためにいくつかの macOS 権限を要求する場合があります。このページでは、各権限の目的と管理方法について説明します。

## ファイルとフォルダ

システム上のあらゆる場所にあるアーカイブにアクセスするために、NueZip はファイルアクセス権限を必要とします。

**用途**: アーカイブファイルの読み取り、内容の展開、新しいアーカイブの作成。

**管理**: システム設定 → **プライバシーとセキュリティ** → **ファイルとフォルダ**

初回起動時にプロンプトが表示されたらアクセスを許可してください。アクセスはいつでも管理または取り消しができます。

## Finder 機能拡張

NueZip には、右クリックのコンテキストメニューオプションを追加する Finder 機能拡張が含まれています。

**用途**: Finder から直接、アーカイブファイルを右クリックして NueZip で展開、圧縮、または開く。

**有効化**: システム設定 → **プライバシーとセキュリティ** → **機能拡張** → **Finder 機能拡張** → **NueZip** を有効にする

## 通知

NueZip は、長時間実行される操作（バッチ展開、大容量アーカイブの圧縮）に対して通知を表示する場合があります。

**用途**: バックグラウンド操作の完了をお知らせすること。

**管理**: システム設定 → **通知** → **NueZip**

## 全ディスクアクセス（オプション）

システムで保護された場所にアーカイブを展開するために、NueZip は全ディスクアクセスを要求する場合があります。

**用途**: ユーザーフォルダ外の場所へ展開されたファイルを書き込むこと。

**管理**: システム設定 → **プライバシーとセキュリティ** → **全ディスクアクセス**

この権限はオプションであり、システム全体の場所を扱う場合にのみ必要です。

## ターミナルで権限をリセットする

権限ダイアログが閉じられたり、状態が不整合になったりした場合は、`tccutil` を使用して macOS の権限プロンプトをリセットできます：

```bash
# NueZip の権限をリセットする
tccutil reset All com.w3cub.nuezip
```

`tccutil` の実行後、アプリを再起動し、再度その機能を呼び出すとプロンプトが再表示されます。

## トラブルシューティング

- 通知が表示されない場合は、**通知** 権限が許可されているか確認してください。
- 権限を変更した後は、変更を反映させるために必ず NueZip を終了して再起動してください。

詳しくは [トラブルシューティングガイド](./troubleshooting.md) を参照してください。
