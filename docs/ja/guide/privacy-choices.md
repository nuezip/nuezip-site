# プライバシーの選択

NueZip は完全にオフラインのアプリケーションです。すべてのデータがお客様のデバイス上に留まるため、当社が個人情報を収集、販売、または共有することはありません。

## ローカルに保持するデータ

NueZip はすべてのデータをお客様の Mac 上にローカルに保存します：
- アプリの設定と構成
- 最近使用したファイル一覧
- デバッグログ（有効な場合）
- キーチェーンに保存されたパスワード（保存することを選択した場合）

これらのデータがサーバーにアップロードされることはありません。

## お客様の権利

NueZip は当社のサーバー上に個人データを収集または保存しないため、当社がアクセス、削除、または転送できる個人データは存在しません。すべてのデータは、アプリ内で直接管理するか、アプリのコンテナフォルダを削除することで管理できます：

```bash
rm -rf ~/Library/Containers/com.w3cub.nuezip
```

## 販売しません

NueZip はいかなる個人情報も販売しません。いかなる種類のサードパーティのアナリティクス、広告、トラッキングサービスも使用しません。
