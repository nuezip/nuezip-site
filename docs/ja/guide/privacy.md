# プライバシーポリシー

NueZip は完全にオフライン優先のアプリケーションとして設計されています。お客様のプライバシーを最優先としています。

## ローカルのみの設計

- すべてのアーカイブ操作 — 圧縮、展開、変換、暗号化 — はお使いの Mac 上でのみ実行されます。
- NueZip はお客様のファイルやデータを外部のサーバーにアップロードしません。
- アプリを使用するためにアカウントや登録は不要です。
- 通常の操作にインターネット接続は必要ありません。

## 収集しないもの

- お客様のファイル、文書、アーカイブの内容は収集しません。
- お客様のアクティビティ、閲覧行動、使用パターンを追跡しません。
- ファイルのメタデータや個人情報を外部サーバーに送信しません。
- サードパーティのアナリティクス、広告、トラッキング SDK を含みません。
- テレメトリシステムは一切ありません。

## ローカルに保存されるデータ

以下のデータはお客様のデバイス上にのみ保存されます：
- **アプリ設定**: テーマ、言語の好み、圧縮の好み
- **ライセンスキー**: 購入した場合（ローカルのキーチェーンに安全に保存）
- **最近使用したファイル一覧**: クイックアクセス用の最近開いたアーカイブ
- **パスワード記録**: 保存することを選択した場合、ローカルのキーチェーンに保存
- **ログ**: トラブルシューティング用のデバッグログ（いつでも削除可能）

## アプリが使用する権限

- **ファイルとフォルダ**: アーカイブファイルの読み取りと内容の展開に必要です。
- **Finder 機能拡張**: オプション。Finder に右クリックのコンテキストメニュー項目を追加します。
- **通知**: オプション。長時間実行されるタスクの完了通知用です。

これらの権限は **システム設定 → プライバシーとセキュリティ** でいつでも管理できます。

## アプリ内購入／ライセンス

ライセンスの購入は Apple が Mac App Store を通じて処理します。NueZip はお客様の支払い情報を受け取ったり保存したりすることはありません。ライセンスのレシートは所有権の確認のためにローカルに保存されます。

## サードパーティサービス

NueZip はサードパーティのアナリティクス、広告、トラッキングサービスを一切含みません。アプリは完全に自己完結しています。

## プライバシーに関するリクエスト

NueZip はすべてのデータをお客様のデバイス上にローカルに保存するため、当社のサーバー上に個人データを保持することはありません。プライバシーについてご質問がある場合は、お問い合わせください。

## お問い合わせ

プライバシーに関するご質問は、[GitHub Issues](https://github.com/nuezip/nuezip/issues) で issue を作成するか、メールでお問い合わせください。
