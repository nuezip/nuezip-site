# トラブルシューティング

このページでは、macOS 上の NueZip でよくある問題とその解決方法をまとめています。

## アプリが起動しない、または起動時にクラッシュする

症状: NueZip が開かない、すぐにクラッシュする、または予期しないエラーが表示される。

試すべき手順：

1. macOS のバージョンが最小要件（macOS 14 Sonoma+）を満たしていることを確認してください。
2. アプリを終了し、再起動してください。
3. Mac を再起動してください。
4. アプリが GitHub Releases からダウンロードされた場合は、最新のビルドまたは公証済みのバージョンをダウンロードしてみてください。
5. 問題が続く場合は、ログを収集（以下参照）して issue を作成してください。

## RAR アーカイブを開けない

症状: NueZip が `.rar` ファイルを開けない、またはエラーを表示する。

チェックリスト：

1. RAR ファイルが破損していないことを確認してください。The Unarchiver などの別のツールで開いてみてください。
2. マルチボリュームの RAR アーカイブには、すべてのパート（`.part1.rar`、`.part2.rar` など）が揃っている必要があります。
3. パスワードで保護された RAR アーカイブには、正しいパスワードが必要です。
4. RAR5 フォーマットはサポートされています。それより古い RAR フォーマットをお持ちの場合はご報告ください。

## パスワードエラーで展開に失敗する

症状: "パスワードが違います" または復号エラーで展開に失敗する。

チェックリスト：

1. パスワードが正しいことを確認してください — パスワードは大文字小文字を区別します。
2. 正しい暗号化方式がサポートされていることを確認してください（ZIP の場合は AES-256）。
3. パスワードマネージャーからパスワードを再入力してみてください。

## Finder 機能拡張が表示されない

症状: Finder でアーカイブを右クリックしても NueZip のオプションが表示されない。

チェックリスト：

1. 機能拡張を有効にしてください：システム設定 → プライバシーとセキュリティ → 機能拡張 → Finder 機能拡張 → **NueZip** を有効にする。
2. Finder を再起動してください：アクティビティモニタで Finder を右クリック → 再起動、またはターミナルで `killall Finder` を実行してください。
3. それでも機能拡張が表示されない場合は、アプリを再インストールしてください。

## ライセンス／購入が表示されない

症状: NueZip を購入したのに、試用版のまま表示される。

チェックリスト：

1. 購入に使用したものと同じ Apple ID でサインインしていることを確認してください。
2. 購入を復元してください：NueZip → 設定 → ライセンス → 購入を復元。
3. 問題が続く場合はサポートに連絡してください。

## デバッグログの収集方法

問題の診断を支援するため、NueZip からデバッグログを収集します：

```bash
# 共有のためにログをデスクトップにコピーする
cp ~/Library/Containers/com.w3cub.nuezip/Data/Library/Logs/NueZip/nuezip.log ~/Desktop/NueZip-Logs
```

その後、[GitHub Issues](https://github.com/nuezip/nuezip/issues) で issue を作成し、ログを添付してください。

## 権限に関する問題

機能が権限を求めたが、許可しても動作しない場合：

1. 権限を許可した後、アプリを終了して再起動してください。
2. 必要に応じて、`tccutil` で権限プロンプトをリセットしてください（[権限ガイド](./permissions.md) 参照）。

## パフォーマンスの問題

アプリが遅い、または応答しない場合：

1. 他の負荷の高いアプリケーションを閉じてください。
2. より小さなアーカイブを展開して、問題を切り分けてみてください。
3. 時間の経過とともにパフォーマンスが低下する場合は、アプリを再起動してください。

## ログを確認する

クラッシュや問題のトラブルシューティングには、アプリケーションログが最も役立つ情報です。サンドボックス化された（App Store の）ビルドでは、以下を確認してください：

```
~/Library/Containers/com.w3cub.nuezip/Data/Library/Logs/NueZip/nuezip.log
```



## アプリのリセット

設定をリセットし、ローカルデータをクリアするには：

1. NueZip を終了する
2. コンテナを削除する（注意 — これによりすべての設定が削除されます）：

```bash
rm -rf ~/Library/Containers/com.w3cub.nuezip
```

3. NueZip を再起動し、再設定してください。

## 問題を報告する

issue を作成する際は、以下を含めてください：

- macOS のバージョン（Apple メニュー → この Mac について）
- NueZip のバージョン（NueZip → バージョン情報）
- 再現手順
- ログ（収集方法については [ログを確認する](#view-logs) セクションを参照）

これにより、メンテナーは問題を特定して迅速に修正できます。
