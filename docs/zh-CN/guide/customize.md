# 自定义

通过自定义你的归档管理体验，让 NueZip 真正属于你。本指南涵盖所有你可以个性化的内容。

## 通用偏好

打开 **NueZip → 设置**（或按下 `Cmd+,`）以访问所有自定义选项。

### 外观
- **主题**：在浅色、深色或跟随系统（跟随 macOS 外观）之间选择
- **图标样式**：设置为单色或彩色菜单栏图标
- **语言**：从支持的语言中选择（英语、中文、日本語、한국어 等）

## 压缩默认值

设置你偏好的压缩默认值：

| 设置 | 选项 | 描述 |
|---------|---------|-------------|
| **默认格式** | ZIP、7z、TAR、GZIP、BZIP2、XZ | 用于快速压缩的归档格式 |
| **压缩级别** | 存储、快速、普通、最大、极限 | 速度与压缩比之间的权衡 |
| **加密** | 无、AES-128、AES-256 | ZIP/7z 归档的默认加密 |
| **卷大小** | 自定义（MB） | 多卷归档的默认拆分大小 |

### 示例配置

日常使用：
- **格式**：ZIP
- **级别**：普通
- **加密**：AES-256（用于敏感文件）
- **分卷**：关闭

归档用途：
- **格式**：7-Zip
- **级别**：极限
- **加密**：AES-256
- **分卷**：4.7 GB（以适配 DVD）

## 解压偏好

自定义解压行为：

- **默认解压到子文件夹**：解压时自动创建带名称的文件夹
- **解压后打开文件夹**：在 Finder 中显示解压出的内容
- **覆盖行为**：询问、总是覆盖或跳过已有文件
- **保留文件日期**：保留归档中的原始时间戳

## Finder 扩展

管理 Finder 上下文菜单集成：

- **启用/禁用**：开启或关闭右键菜单项
- **快速操作**：选择哪些操作出现在上下文菜单中
  - 解压到此
  - 解压到文件夹
  - 压缩为 ZIP
  - 带选项压缩

在以下位置管理：**系统设置 → 隐私与安全性 → 扩展 → Finder 扩展**

## 菜单栏（托盘）图标

自定义菜单栏放置面板：

- **在菜单栏中显示**：启用/禁用托盘图标
- **自动关闭面板**：解压后关闭放置面板
- **最近归档**：显示的最近项目数量
- **关闭时退出**：应用是否在后台保持运行

## 通知

- **显示完成提醒**：长时间操作完成时通知
- **显示错误提醒**：操作失败时显示通知
- **声音**：操作完成时播放声音

## 通用设置

在 **设置 → 通用** 中访问这些设置：

- **语言**：在英语、中文、日本語 等之间切换
- **登录时启动**：登录时 NueZip 自动启动
- **主题**：浅色或深色模式（默认跟随系统）
- **菜单栏图标**：显示或隐藏菜单栏图标

## 提示

- 一次性设置你喜欢的压缩默认值，以加快日常归档速度
- 启用 "登录时启动"，让 NueZip 始终一键可达
- 使用 Finder 扩展获得最快的解压/压缩工作流
- 定期在系统设置中检查文件夹访问权限，保持整洁
