# 简介

## 关于 NueZip

NueZip 是一款为 macOS 打造的专业归档管理器，主打速度、可靠性和易用性。无论是压缩文件、解压归档、转换格式，还是管理加密归档，NueZip 都能以原生的 macOS 体验为你妥善处理。

NueZip 基于 Swift 6 和 SwiftUI 构建，充分利用 Apple Silicon 与 macOS 技术，提供一款快速、轻量且安全的归档管理工具。

## 核心功能

### 📦 **多格式支持**
NueZip 支持所有主流归档格式：
- **RAR** — 只读，支持多卷
- **ZIP** — 通用压缩，支持 AES 加密
- **7-Zip** — 高压缩比，采用 LZMA2
- **TAR** — 归档打包，可选 GZIP/BZIP2
- **GZIP / BZIP2** — 独立的压缩格式

### ⚡ **快速解压**
双引擎架构会为每种格式选择最优的后端，确保尽可能快的解压速度。

### 🔐 **密码保护与加密**
使用行业标准加密创建带密码保护的归档。内置密码管理器将凭据安全地存储在你本地的钥匙串中。

### 📋 **批量操作**
一次性处理多个文件：
- **批量压缩** — 将多个项目分别压缩为独立的归档
- **批量解压** — 同时解压多个归档
- **批量转换** — 批量在格式之间转换归档
- **批量加密** — 为多个归档应用密码保护

### 🛠️ **高级工具**
- **归档修复** — 修复损坏的 RAR 和 ZIP 归档
- **格式转换** — 在任意支持的格式之间转换
- **性能基准测试** — 测试压缩速度与评级
- **归档搜索** — 按名称在归档中查找文件
- **文件信息查看器** — 查看归档条目的详细元数据
- **分卷/拆分支持** — 创建多卷归档

### 🖥️ **原生 macOS 体验**
- **Swift 6 + SwiftUI** — 现代、响应式的界面
- **Apple Silicon 原生** — 针对 M 系列芯片优化
- **Finder 集成** — 右键上下文菜单扩展
- **拖放** — 通过菜单栏放置面板快速访问
- **极低的资源占用** — 轻量的后台运行

## 系统要求

- **操作系统**：macOS 14 Sonoma 或更高版本
- **CPU**：Apple Silicon（M 系列）或 Intel（64 位）
- **内存**：最低 4GB，推荐 8GB
- **存储空间**：安装约需 50 MB

## 支持的语言

NueZip 支持英语、简体中文、繁体中文、日语、韩语以及许多其他语言。
