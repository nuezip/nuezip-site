# macOS 权限

为了提供最佳体验，NueZip 可能会请求几项 macOS 权限。本页面说明每项权限的用途以及如何管理它们。

## 文件与文件夹

为了访问系统中任意位置的归档，NueZip 需要文件访问权限。

**用途**：读取归档文件、解压内容以及创建新归档。

**管理**：系统设置 → **隐私与安全性** → **文件与文件夹**

在首次启动弹出提示时授予访问权限。你可以随时管理或撤销访问权限。

## Finder 扩展

NueZip 包含一个 Finder 扩展，用于添加右键上下文菜单选项。

**用途**：在 Finder 中右键点击归档文件，即可直接解压、压缩或使用 NueZip 打开。

**启用**：系统设置 → **隐私与安全性** → **扩展** → **Finder 扩展** → 启用 **NueZip**

## 通知

NueZip 可能会针对长时间运行的操作（批量解压、大型归档压缩）显示通知。

**用途**：在后台操作完成时提醒你。

**管理**：系统设置 → **通知** → **NueZip**

## 完全磁盘访问（可选）

为了将归档解压到系统保护的位置，NueZip 可能会请求完全磁盘访问权限。

**用途**：将解压出的文件写入用户文件夹之外的位置。

**管理**：系统设置 → **隐私与安全性** → **完全磁盘访问**

此权限为可选，仅在你处理系统级位置时才需要。

## 使用终端重置权限

如果权限对话框被关闭或状态不一致，你可以使用 `tccutil` 重置 macOS 的权限提示：

```bash
# 重置 NueZip 的权限
tccutil reset All com.w3cub.nuezip
```

运行 `tccutil` 后，重启应用并再次触发该功能以重新弹出提示。

## 故障排除

- 如果通知不显示，请检查 **通知** 权限是否已授予。
- 修改权限后，务必退出并重新打开 NueZip，更改才能生效。

如需更多帮助，请访问 [故障排除指南](./troubleshooting.md)。
