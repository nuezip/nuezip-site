# 隐私选项

NueZip 是一款完全离线的应用。由于你的所有数据都保存在设备上，我们不会收集、出售或共享任何个人信息。

## 我们本地持有的数据

NueZip 将所有数据本地存储在你的 Mac 上：
- 应用偏好和配置
- 最近文件列表
- 调试日志（如已启用）
- 钥匙串中存储的密码（如果你选择保存）

这些数据都不会被上传到任何服务器。

## 你的权利

由于 NueZip 不会在我们的服务器上收集或存储个人数据，因此没有我们可以访问、删除或传输的个人数据。你所有数据都可以直接在应用内管理，或通过移除应用的容器文件夹来管理：

```bash
rm -rf ~/Library/Containers/com.w3cub.nuezip
```

## 不出售

NueZip 不出售任何个人信息。我们不使用任何类型的第三方分析、广告或追踪服务。

## 联系方式

如果你对隐私选项有疑问，请在以下地址提交 issue：
`https://github.com/nuezip/nuezip/issues`
