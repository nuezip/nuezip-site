# 隐私政策

NueZip 被设计为完全离线优先的应用。你的隐私是我们的首要任务。

## 仅本地设计

- 所有归档操作 — 压缩、解压、转换、加密 — 完全在你的 Mac 上运行。
- NueZip 不会将你的文件或数据上传到任何外部服务器。
- 使用本应用无需账户或注册。
- 正常运行不需要互联网连接。

## 我们不收集的内容

- 我们不收集你的文件、文档或归档内容。
- 我们不追踪你的活动、浏览行为或使用模式。
- 我们不会向外部服务器发送任何文件元数据或个人信息。
- 我们不包含任何第三方分析、广告或追踪 SDK。
- 我们没有遥测系统。

## 本地存储的数据

以下数据仅存储在你的设备上：
- **应用设置**：主题、语言偏好、压缩偏好
- **许可证密钥**：如已购买（安全存储在本地钥匙串中）
- **最近文件列表**：最近打开的归档，便于快速访问
- **密码记录**：如果你选择保存，则存储在本地钥匙串中
- **日志**：用于故障排除的调试日志（可随时删除）

## 应用使用的权限

- **文件与文件夹**：读取归档文件和解压内容所需。
- **Finder 扩展**：可选，在 Finder 中添加右键上下文菜单项。
- **通知**：可选，用于长时间任务的完成提醒。

你可以随时在 **系统设置 → 隐私与安全性** 中管理这些权限。

## 应用内购买 / 许可证

许可证购买由 Apple 通过 Mac App Store 处理。NueZip 不会接收或存储你的支付信息。购买收据本地存储以验证所有权。

## 第三方服务

NueZip 不包含任何第三方分析、广告或追踪服务。该应用完全自给自足。

## 隐私请求

由于 NueZip 将所有数据本地存储在你设备上，我们在服务器上不持有任何个人数据。如果你对隐私有疑问，请联系我们。

## 联系方式

如有隐私相关问题，请在 [GitHub Issues](https://github.com/nuezip/nuezip/issues) 上提交 issue 或通过电子邮件联系我们。
