# 自訂設定

透過自訂您的壓縮檔管理體驗，讓 NueZip 真正屬於您。本指南涵蓋所有可個人化的項目。

## 一般偏好

開啟 **NueZip → 設定**（或按下 `Cmd+,`）以存取所有自訂選項。

### 外觀
- **主題**：在淺色、深色或系統（跟隨 macOS 外觀）之間選擇
- **圖示樣式**：設定為單色或彩色選單列圖示
- **語言**：從支援的語言中選擇（English、中文、日本語、한국어 等）

## 壓縮預設值

設定您偏好的壓縮預設值：

| 設定 | 選項 | 說明 |
|---------|---------|-------------|
| **預設格式** | ZIP、7z、TAR、GZIP、BZIP2、XZ | 快速壓縮所用的壓縮檔格式 |
| **壓縮層級** | Store、Fast、Normal、Maximum、Ultra | 速度與壓縮比之間的取捨 |
| **加密** | None、AES-128、AES-256 | ZIP/7z 壓縮檔的預設加密 |
| **卷大小** | 自訂（MB） | 多分割卷壓縮檔的預設分割大小 |

### 設定範例

針對日常使用：
- **格式**：ZIP
- **層級**：Normal
- **加密**：AES-256（針對敏感檔案）
- **卷**：關閉

針對封存：
- **格式**：7-Zip
- **層級**：Ultra
- **加密**：AES-256
- **卷**：4.7 GB（以符合 DVD 容量）

## 解壓縮偏好

自訂解壓縮行為：

- **預設解壓縮到子資料夾**：解壓縮時自動建立具名資料夾
- **解壓縮後開啟資料夾**：在 Finder 中顯示解壓縮出的內容
- **覆寫行為**：詢問、一律覆寫，或跳過現有檔案
- **保留檔案日期**：保留壓縮檔中的原始時間戳記

## Finder 擴充功能

管理 Finder 右鍵選單整合：

- **啟用/停用**：開啟或關閉右鍵選單項目
- **快速動作**：選擇哪些動作出現在右鍵選單中
  - 在此解壓縮
  - 解壓縮到資料夾
  - 壓縮為 ZIP
  - 使用選項壓縮

請在以下位置管理：**系統設定 → 隱私權與安全性 → 擴充功能 → Finder 擴充功能**

## 選單列（匣子）圖示

自訂選單列拖放面板：

- **顯示於選單列**：啟用/停用匣子圖示
- **自動關閉面板**：解壓縮後關閉拖放面板
- **最近壓縮檔**：顯示的最近項目數量
- **關閉時退出**：App 是否留在背景執行

## 通知

- **顯示完成提醒**：長時間操作完成時發出通知
- **顯示錯誤提醒**：對失敗的操作顯示通知
- **音效**：操作完成時播放音效

## 一般設定

請在 **設定 → 一般** 中存取這些項目：

- **語言**：在 English、中文、日本語 等之間切換
- **登入時啟動**：登入時 NueZip 自動啟動
- **主題**：淺色或深色模式（預設跟隨系統）
- **選單列圖示**：顯示或隱藏選單列圖示

## 小訣竅

- 一次設定好您喜愛的壓縮預設值，加快日常封存速度
- 啟用「登入時啟動」，讓 NueZip 永遠只需一鍵即可使用
- 使用 Finder 擴充功能以獲得最快的解壓縮/壓縮工作流程
- 定期在系統設定中檢視資料夾存取權，保持整潔
