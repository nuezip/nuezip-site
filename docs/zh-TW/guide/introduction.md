# 產品介紹

## 關於 NueZip

NueZip 是一款專為 macOS 打造的專業壓縮檔管理工具，以速度、可靠性和易用性為設計核心。無論您需要壓縮檔案、解壓縮檔、轉換格式，還是管理受密碼保護的壓縮檔，NueZip 都能以原生 macOS 體驗一手包辦。

NueZip 使用 Swift 6 與 SwiftUI 打造，充分發揮 Apple Silicon 與 macOS 技術的優勢，提供一款快速、輕量且安全的壓縮檔管理工具。

## 主要功能

### 📦 **多格式支援**
NueZip 支援所有主流壓縮檔格式：
- **RAR** — 唯讀，支援多分割卷
- **ZIP** — 通用壓縮，支援 AES 加密
- **7-Zip** — 高壓縮比，採用 LZMA2
- **TAR** — 封存打包，可搭配選用的 GZIP/BZIP2
- **GZIP / BZIP2** — 獨立壓縮格式

### ⚡ **極速解壓縮**
雙引擎架構會針對每種格式選擇最佳後端，確保最快的解壓縮速度。

### 🔐 **密碼保護與加密**
使用業界標準加密建立受密碼保護的壓縮檔。內建的密碼管理員會將憑證安全地儲存在您的本機鑰匙圈中。

### 📋 **批次操作**
一次處理多個檔案：
- **批次壓縮** — 將多個項目分別壓縮成個別的壓縮檔
- **批次解壓縮** — 同時解壓縮多個壓縮檔
- **批次轉換** — 大量轉換壓縮檔之間的格式
- **批次加密** — 為多個壓縮檔套用密碼保護

### 🛠️ **進階工具**
- **壓縮檔修復** — 修復損毀的 RAR 與 ZIP 壓縮檔
- **格式轉換** — 在任何受支援的格式之間互相轉換
- **效能測試** — 測試壓縮速度與評級
- **壓縮檔搜尋** — 依名稱在壓縮檔中尋找檔案
- **檔案資訊檢視器** — 檢視壓縮檔項目的詳細中繼資料
- **分割卷支援** — 建立多分割卷的壓縮檔

### 🖥️ **原生 macOS 體驗**
- **Swift 6 + SwiftUI** — 現代、反應靈敏的介面
- **Apple Silicon 原生** — 針對 M 系列晶片優化
- **Finder 整合** — 右鍵選單擴充功能
- **拖放操作** — 透過選單列拖放面板快速存取
- **極低資源占用** — 輕量的背景運作

## 系統需求

- **作業系統**：macOS 14 Sonoma 或更新版本
- **CPU**：Apple Silicon（M 系列）或 Intel（64 位元）
- **記憶體**：最低 4GB RAM，建議 8GB
- **儲存空間**：安裝約需 50 MB

## 支援語言

NueZip 支援英文、簡體中文、繁體中文、日文、韓文，以及許多其他語言。
