# macOS 權限

為了提供最佳的體驗，NueZip 可能會要求數項 macOS 權限。本頁說明每項權限的用途以及管理方式。

## 檔案與資料夾

為了能存取系統上任何位置的壓縮檔，NueZip 需要檔案存取權限。

**用途**：讀取壓縮檔檔案、解壓縮內容，以及建立新壓縮檔。

**管理**：系統設定 → **隱私權與安全性** → **檔案與資料夾**

請在首次啟動時出現提示時授予存取權。您可以隨時管理或撤銷存取權。

## Finder 擴充功能

NueZip 包含一個 Finder 擴充功能，會新增右鍵選單選項。

**用途**：在 Finder 中右鍵點擊壓縮檔，即可直接解壓縮、壓縮，或使用 NueZip 開啟。

**啟用**：系統設定 → **隱私權與安全性** → **擴充功能** → **Finder 擴充功能** → 啟用 **NueZip**

## 通知

NueZip 可能會針對長時間執行的操作（批次解壓縮、大型壓縮檔壓縮）顯示通知。

**用途**：在背景操作完成時提醒您。

**管理**：系統設定 → **通知** → **NueZip**

## 完全磁碟存取權（選用）

若要將壓縮檔解壓縮到系統保護的位置，NueZip 可能會要求完全磁碟存取權。

**用途**：將解壓縮出的檔案寫入使用者資料夾以外的位置。

**管理**：系統設定 → **隱私權與安全性** → **完全磁碟存取權**

此權限為選用，僅在您需要處理全系統範圍的位置時才需要。

## 使用終端機重置權限

如果權限對話框被關閉，或狀態不一致，您可以使用 `tccutil` 重置 macOS 的權限提示：

```bash
# 重置 NueZip 的權限
tccutil reset All com.w3cub.nuezip
```

執行 `tccutil` 後，請重新啟動 App 並再次觸發該功能，以重新彈出提示。

## 疑難排解

- 如果通知沒有出現，請檢查是否已授予 **通知** 權限。
- 變更權限後，請務必退出並重新開啟 NueZip，讓變更生效。

如需更多協助，請參閱[疑難排解指南](./troubleshooting.md)。
