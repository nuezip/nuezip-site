# 隱私選擇

NueZip 是一款完全離線的應用程式。由於您的所有資料都保留在裝置上，我們不會蒐集、販售或分享任何個人資訊。

## 我們在本機持有的資料

NueZip 將所有資料儲存在您 Mac 的本機上：
- App 偏好與設定
- 最近檔案清單
- 除錯日誌（若已啟用）
- 儲存在鑰匙圈中的密碼（若您選擇儲存）

這些資料都不會被上傳到任何伺服器。

## 您的權利

由於 NueZip 不會在我們的伺服器上蒐集或儲存個人資料，因此我們沒有可存取、刪除或移轉的個人資料。您所有資料都可以直接在 App 內管理，或是透過移除 App 的 container 資料夾來處理：

```bash
rm -rf ~/Library/Containers/com.w3cub.nuezip
```

## 不販售

NueZip 不販售任何個人資訊。我們不使用任何形式的第三方分析、廣告或追蹤服務。

## 聯絡方式

若您對隱私選擇有任何疑問，請在以下位置開立 issue：
`https://github.com/nuezip/nuezip/issues`
