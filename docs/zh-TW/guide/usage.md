# 使用教學

## 開啟壓縮檔

### 雙擊開啟

NueZip 會註冊為所有受支援壓縮檔格式的預設處理程式。只要雙擊任何壓縮檔檔案（`.zip`、`.rar`、`.7z`、`.tar`、`.gz`、`.bz2`、`.xz`、`.zst`），即可在 NueZip 的主視窗中開啟它。

### 使用 NueZip 開啟（Finder 右鍵選單）

右鍵點擊任何壓縮檔，並從選單中選擇 **使用 NueZip 開啟**。Finder 擴充功能也提供快速動作：

- **在此解壓縮** — 將壓縮檔內容解壓縮到目前資料夾
- **解壓縮到「資料夾名稱/」** — 解壓縮到具名的子資料夾
- **壓縮為 ZIP** — 將選取的檔案/資料夾壓縮成 ZIP 壓縮檔
- **使用 NueZip 開啟** — 在主瀏覽視窗中開啟

### 拖放到匣子（Tray）

將任何壓縮檔拖曳到 NueZip 的選單列圖示上，即可在拖放面板中快速開啟以便立即存取。您也可以將檔案拖曳到匣子圖示上進行壓縮。

## 解壓縮檔

### 基本解壓縮

1. 在 NueZip 中開啟一個壓縮檔
2. 點擊工具列中的 **解壓縮** 按鈕
3. 選擇目的地資料夾
4. 點擊 **解壓縮**

### 從 Finder 快速解壓縮

在 Finder 中右鍵點擊壓縮檔，並選擇下列其中一項快速動作：
- **在此解壓縮** — 直接解壓縮到目前資料夾
- **解壓縮到「[壓縮檔名稱]/」** — 解壓縮到具名的子資料夾，讓檔案整齊有序

### 使用密碼解壓縮

對於受密碼保護的壓縮檔，NueZip 會提示輸入密碼。內建的密碼管理員可以將憑證安全地儲存在您的本機鑰匙圈中，供日後使用。

## 壓縮檔

### 建立新壓縮檔

1. 在 NueZip 的主視窗中選取檔案或資料夾
2. 點擊工具列中的 **壓縮** 按鈕
3. 選擇壓縮檔格式（ZIP、7z、TAR、GZIP 等）
4. 設定壓縮選項（層級、加密方式）
5. 點擊 **壓縮**

### 從 Finder 壓縮

在 Finder 中右鍵點擊檔案/資料夾，並選擇 **使用 NueZip 壓縮**：
- **壓縮為 ZIP** — 快速建立 ZIP 壓縮檔
- **使用選項壓縮** — 以進階設定開啟 NueZip

### 透過拖放壓縮

將檔案拖曳到 NueZip 的選單列匣子圖示上，即可快速建立 ZIP 壓縮檔。

## 批次操作

### 批次壓縮

1. 在 NueZip 中選取多個項目
2. 從工具列或檔案選單中選擇 **批次壓縮**
3. 每個項目都會被壓縮成獨立的壓縮檔

### 批次解壓縮

1. 在 NueZip 中選取多個壓縮檔
2. 從工具列或檔案選單中選擇 **批次解壓縮**
3. 所有壓縮檔都會同時解壓縮

### 批次轉換

1. 選取一個或多個壓縮檔
2. 選擇 **轉換** → 選取目標格式
3. NueZip 會將每個壓縮檔重新壓縮成所選格式

### 批次加密

1. 選取多個 ZIP 壓縮檔
2. 選擇 **批次加密**
3. 設定密碼 — 所有選取的壓縮檔都會受到密碼保護

## 格式轉換

在任意受支援的格式之間轉換壓縮檔：

1. 開啟一個壓縮檔
2. 點擊工具列中的 **轉換**
3. 選取目標格式（例如 RAR → ZIP、7z → TAR.GZ）
4. 選擇輸出位置
5. 點擊 **轉換**

## 壓縮檔修復

針對損毀的 RAR 或 ZIP 壓縮檔：

1. 開啟損毀的壓縮檔
2. 點擊工具列中的 **修復**
3. NueZip 會嘗試重建壓縮檔資料
4. 修復後的壓縮檔會另存為新檔案

## 壓縮檔搜尋

在壓縮檔中尋找特定檔案：

1. 點擊工具列中的 **搜尋** 按鈕
2. 輸入檔名模式
3. NueZip 會搜尋開啟的壓縮檔中的所有項目
4. 結果會顯示完整路徑，方便快速導覽

## 效能測試

測試您系統的壓縮效能：

1. 前往 **工具 → 效能測試**
2. NueZip 會使用各種格式與設定執行壓縮測試
3. 結果會顯示每種格式的壓縮速度（MB/s）與壓縮比
4. 可用此來比較不同壓縮方法之間的效能

## 多分割卷（Split）壓縮檔

為大型資料建立分割壓縮檔：

1. 在壓縮過程中，啟用 **分割為多個卷**
2. 選擇卷大小（例如 100 MB、650 MB、4.7 GB，或自訂）
3. NueZip 會建立編號的分割檔（`.zip.001`、`.zip.002` 等）
4. 若要解壓縮，請開啟第一個分割檔 — NueZip 會自動載入其餘部分

- **密碼**：為加密壓縮檔提供密碼
- **包裝進資料夾**：若壓縮檔沒有單一根目錄，自動建立根資料夾
- **完成後開啟**：解壓縮完成後在 Finder 中顯示解壓出的檔案
- **保留損壞檔案**：保留錯誤發生前已解壓出的任何檔案（用於部分復原）
- **更新模式**：選擇如何處理現有檔案（覆寫、跳過、重新命名）

### 批次解壓縮

1. 前往 **工具 → 批次解壓縮**
2. 點擊 **加入檔案...** 選取壓縮檔
3. 選擇目的地資料夾
4. 可選擇啟用 **解壓縮後刪除來源檔案**
5. 點擊 **開始**

## 建立壓縮檔

### 壓縮檔案

1. 點擊工具列中的 **壓縮** 按鈕
2. 選取要壓縮的檔案（或將它們拖放進視窗）
3. 選擇 **壓縮檔格式**：ZIP、7Z、TAR、GZIP、BZIP2
4. 設定 **壓縮方式** 與層級
5. 設定 **儲存位置** 與壓縮檔名稱
6. 可選擇設定 **密碼** 進行加密
7. 可選擇設定 **分割大小** 以建立多分割卷壓縮檔
8. 點擊 **壓縮**

### 將檔案加入現有壓縮檔

1. 在 NueZip 中開啟現有的壓縮檔
2. 點擊工具列中的 **加入檔案**
3. 選取要加入的檔案
4. 點擊 **加入**

## 批次操作

### 批次壓縮

1. 前往 **工具 → 批次壓縮**
2. 點擊 **選取檔案/資料夾...** 選擇項目
3. 每個選取的項目都會成為獨立的壓縮檔
4. 設定輸出的 **格式**、**儲存位置** 與檔案命名前置詞
5. 點擊 **開始**

### 批次轉換格式

1. 前往 **工具 → 批次轉換格式**
2. 點擊 **加入檔案...** 選取來源壓縮檔
3. 選擇 **目標格式**
4. 可選擇啟用 **轉換後刪除來源檔案**
5. 點擊 **開始**

### 批次加密

1. 前往 **工具 → 批次加密**
2. 點擊 **加入檔案...** 選取壓縮檔
3. 輸入 **密碼**
4. 點擊 **加密**

## 進階功能

### 壓縮檔修復

修復損毀或受損的壓縮檔：

1. 選取受損的壓縮檔
2. 前往 **工具 → 修復壓縮檔**
3. NueZip 會掃描檔頭、重建目錄，並修復資料區塊
4. 檢視修復結果

### 格式轉換

在格式之間轉換壓縮檔：

1. 開啟壓縮檔或選取檔案
2. 前往 **檔案 → 轉換格式**
3. 選擇目標格式與壓縮層級
4. 可選擇刪除原始檔案
5. 點擊 **轉換**

### 密碼管理員

NueZip 會將壓縮檔密碼安全地儲存在您的本機鑰匙圈中：

1. 前往 **工具 → 密碼管理員**
2. 檢視所有已儲存的密碼
3. 新增、編輯或刪除項目
4. 開啟相符的加密壓縮檔時，密碼會自動套用

### 效能測試

測試您系統的壓縮效能：

1. 前往 **工具 → 效能測試**
2. 選擇測試檔案（或使用預設檔案）
3. 點擊 **測試**
4. 檢視包含壓縮/解壓縮速度與評級的結果

### 壓縮檔搜尋

在壓縮檔中尋找檔案：

1. 開啟壓縮檔
2. 按下 `Cmd+F` 或點擊搜尋圖示
3. 輸入檔名，可選擇是否區分大小寫或比對整個單字
4. 瀏覽搜尋結果並點擊以導覽

## 鍵盤快捷鍵

| 快捷鍵 | 動作 |
|----------|--------|
| `Cmd+O` | 開啟壓縮檔 |
| `Cmd+N` | 新建壓縮檔 |
| `Cmd+E` | 解壓縮 |
| `Cmd+F` | 在壓縮檔中尋找 |
| `Cmd+,` | 開啟設定 |
| `Cmd+W` | 關閉視窗 |
| `Cmd+Q` | 結束應用程式 |
| `Cmd+↑` | 上一層 |
| `Cmd+→` | 向前 |

## 設定

透過 **NueZip → 設定** 或按下 `Cmd+,` 存取設定：

- **一般**：語言、登入時啟動、外觀主題
- **壓縮**：預設格式、壓縮層級、分割大小
- **解壓縮**：預設目的地、包裝行為、衝突處理
- **資料夾存取**：管理資料夾權限與書籤
- **進階**：硬體加速、執行緒數量、暫存目錄
- **隱私**：資料蒐集偏好
