使い方ガイド ​

アーカイブを開く ​

ダブルクリックで開く ​

NueZip は、対応するすべてのアーカイブフォーマットのデフォルトハンドラーとして自身を登録します。アーカイブファイル（.zip、.rar、.7z、.tar、.gz、.bz2、.xz、.zst）をダブルクリックするだけで、NueZip のメインウィンドウで開きます。

NueZip で開く（Finder コンテキストメニュー） ​

任意のアーカイブファイルを右クリックし、コンテキストメニューから NueZip で開く を選択します。Finder 機能拡張は次のクイックアクションも提供します：

  • ここに展開 — アーカイブの内容を現在のフォルダに展開する
  • "フォルダ名/" に展開 — 名前付きのサブフォルダに展開する
  • ZIP に圧縮 — 選択したファイル／フォルダを ZIP アーカイブに圧縮する
  • NueZip で開く — メインのブラウザウィンドウで開く

トレイにドラッグ＆ドロップ ​

アーカイブファイルを NueZip のメニューバーアイコンにドラッグすると、ドロップパネルですばやく開き、即座にアクセスできます。ファイルをトレイアイコンにドラッグして圧縮することもできます。

アーカイブの展開 ​

基本的な展開 ​

  1. NueZip でアーカイブを開く
  2. ツールバーの 展開 ボタンをクリックする
  3. 出力先フォルダを選択する
  4. 展開 をクリックする

Finder からのクイック展開 ​

Finder でアーカイブを右クリックし、次のクイックアクションのいずれかを選択します：

  • ここに展開 — 現在のフォルダに直接展開する
  • "[アーカイブ名]/" に展開 — 整理された状態になるよう、名前付きのサブフォルダに展開する

パスワード付きで展開 ​

パスワードで保護されたアーカイブの場合、NueZip はパスワードを求めます。内蔵のパスワードマネージャーは、資格情報をローカルのキーチェーンに安全に保存し、将来の使用に備えることができます。

アーカイブの圧縮 ​

新しいアーカイブを作成する ​

  1. NueZip のメインウィンドウでファイルまたはフォルダを選択する
  2. ツールバーの 圧縮 ボタンをクリックする
  3. アーカイブフォーマットを選択する（ZIP、7z、TAR、GZIP など）
  4. 圧縮設定（レベル、暗号化方式）を構成する
  5. 圧縮 をクリックする

Finder から圧縮する ​

Finder でファイル／フォルダを右クリックし、NueZip で圧縮 を選択します：

  • ZIP に圧縮 — すばやく ZIP アーカイブを作成する
  • オプションを指定して圧縮 — 詳細設定を指定して NueZip を開く

ドラッグ＆ドロップで圧縮する ​

ファイルを NueZip のメニューバートレイアイコンにドラッグすると、すばやく ZIP アーカイブを作成できます。

バッチ操作 ​

バッチ圧縮 ​

  1. NueZip で複数の項目を選択する
  2. ツールバーまたはファイルメニューから バッチ圧縮 を選択する
  3. 各項目は別々のアーカイブに圧縮されます

バッチ展開 ​

  1. NueZip で複数のアーカイブを選択する
  2. ツールバーまたはファイルメニューから バッチ展開 を選択する
  3. すべてのアーカイブが同時に展開されます

バッチ変換 ​

  1. 1 つ以上のアーカイブを選択する
  2. 変換 を選択 → ターゲットフォーマットを選択する
  3. NueZip は各アーカイブを選択したフォーマットに再圧縮します

バッチ暗号化 ​

  1. 複数の ZIP アーカイブを選択する
  2. バッチ暗号化 を選択する
  3. パスワードを設定する — 選択したすべてのアーカイブがパスワードで保護されます

フォーマット変換 ​

対応する任意のフォーマット間でアーカイブを変換します：

  1. アーカイブを開く
  2. ツールバーの 変換 をクリックする
  3. ターゲットフォーマットを選択する（例：RAR → ZIP、7z → TAR.GZ）
  4. 出力先を選択する
  5. 変換 をクリックする

アーカイブ修復 ​

破損した RAR または ZIP アーカイブの場合：

  1. 破損したアーカイブを開く
  2. ツールバーの 修復 をクリックする
  3. NueZip はアーカイブデータの再構築を試みます
  4. 修復されたアーカイブは新しいファイルとして保存されます

アーカイブ検索 ​

アーカイブ内の特定のファイルを検索します：

  1. ツールバーの 検索 ボタンをクリックする
  2. ファイル名のパターンを入力する
  3. NueZip は開いているアーカイブ内のすべての項目を検索します
  4. 結果はクイックナビゲーションのための完全なパスとともに表示されます

パフォーマンスベンチマーク ​

システムの圧縮パフォーマンスをテストします：

  1. ツール → ベンチマーク に移動する
  2. NueZip はさまざまなフォーマットと設定を使用して圧縮テストを実行します
  3. 結果には各フォーマットの圧縮速度（MB/秒）と比率が表示されます
  4. これを使用して、異なる圧縮方式のパフォーマンスを比較できます

マルチボリューム（分割）アーカイブ ​

大容量データ用に分割アーカイブを作成します：

  1. 圧縮中に ボリュームに分割 を有効にする
  2. ボリュームサイズを選択する（例：100 MB、650 MB、4.7 GB、またはカスタム）
  3. NueZip は連番のパートファイル（.zip.001、.zip.002 など）を作成します
  4. 展開するには、最初のパートファイルを開きます — NueZip は残りを自動的に読み込みます
  • パスワード: 暗号化されたアーカイブのパスワードを指定する
  • フォルダで囲む: アーカイブに単一のルートディレクトリがない場合、ルートフォルダを自動的に作成する
  • 展開後に開く: 完了時に Finder で展開されたファイルを表示する
  • 壊れたファイルを保持: エラー発生前に展開されたファイルを保持する（部分的な復元用）
  • 更新モード: 既存ファイルの処理方法（上書き、スキップ、リネーム）を選択する

バッチ展開 ​

  1. ツール → バッチ展開 に移動する
  2. ファイルを追加... をクリックしてアーカイブファイルを選択する
  3. 出力先フォルダを選択する
  4. 必要に応じて 展開後に元ファイルを削除 を有効にする
  5. 開始 をクリックする

アーカイブの作成 ​

ファイルを圧縮する ​

  1. ツールバーの 圧縮 ボタンをクリックする
  2. 圧縮するファイルを選択する（またはウィンドウにドラッグ＆ドロップする）
  3. アーカイブフォーマット を選択する：ZIP、7Z、TAR、GZIP、BZIP2
  4. 圧縮方式 とレベルを構成する
  5. 保存場所 とアーカイブ名を設定する
  6. 必要に応じて暗号化用の パスワード を設定する
  7. 必要に応じてマルチボリュームアーカイブ用の 分割サイズ を設定する
  8. 圧縮 をクリックする

既存のアーカイブにファイルを追加 ​

  1. NueZip で既存のアーカイブを開く
  2. ツールバーの ファイルを追加 をクリックする
  3. 追加するファイルを選択する
  4. 追加 をクリックする

バッチ操作 ​

バッチ圧縮 ​

  1. ツール → バッチ圧縮 に移動する
  2. ファイル／フォルダを選択... をクリックして項目を選択する
  3. 選択した各項目は別々のアーカイブになります
  4. 出力の フォーマット、保存場所、ファイル名の接頭辞を構成する
  5. 開始 をクリックする

バッチフォーマット変換 ​

  1. ツール → バッチフォーマット変換 に移動する
  2. ファイルを追加... をクリックして元のアーカイブを選択する
  3. ターゲットフォーマット を選択する
  4. 必要に応じて 変換後に元ファイルを削除 を有効にする
  5. 開始 をクリックする

バッチ暗号化 ​

  1. ツール → バッチ暗号化 に移動する
  2. ファイルを追加... をクリックしてアーカイブを選択する
  3. パスワード を入力する
  4. 暗号化 をクリックする

高度な機能 ​

アーカイブ修復 ​

破損または損傷したアーカイブを修復します：

  1. 破損したアーカイブを選択する
  2. ツール → アーカイブを修復 に移動する
  3. NueZip はヘッダーをスキャンし、ディレクトリを再構築し、データブロックを修復します
  4. 修復結果を確認する

フォーマット変換 ​

フォーマット間でアーカイブを変換します：

  1. アーカイブを開くか、ファイルを選択する
  2. ファイル → フォーマット変換 に移動する
  3. ターゲットフォーマットと圧縮レベルを選択する
  4. 必要に応じて元のファイルを削除する
  5. 変換 をクリックする

パスワードマネージャー ​

NueZip はアーカイブのパスワードをローカルのキーチェーンに安全に保存します：

  1. ツール → パスワードマネージャー に移動する
  2. 保存されているすべてのパスワードを表示する
  3. 項目の追加、編集、削除を行う
  4. 一致する暗号化アーカイブを開く際、パスワードは自動的に適用されます

パフォーマンスベンチマーク ​

システムの圧縮パフォーマンスをテストします：

  1. ツール → パフォーマンスベンチマーク に移動する
  2. テストファイルを選択する（またはデフォルトを使用する）
  3. テスト をクリックする
  4. 圧縮／展開速度と評価を含む結果を表示する

アーカイブ検索 ​

アーカイブ内のファイルを検索します：

  1. アーカイブを開く
  2. Cmd+F を押すか、検索アイコンをクリックする
  3. ファイル名を入力し、必要に応じて大文字小文字の区別や単語全体への一致を行う
  4. 検索結果を参照し、クリックして移動する

キーボードショートカット ​

ショートカット操作
Cmd+Oアーカイブを開く
Cmd+N新規アーカイブ
Cmd+E展開
Cmd+Fアーカイブ内を検索
Cmd+,設定を開く
Cmd+Wウィンドウを閉じる
Cmd+Qアプリケーションを終了
Cmd+↑1 つ上の階層へ移動
Cmd+→前に進む

設定 ​

NueZip → 設定 から、または Cmd+, を押して設定にアクセスします：

  • 一般: 言語、ログイン時の起動、外観テーマ
  • 圧縮: デフォルトフォーマット、圧縮レベル、分割サイズ
  • 展開: デフォルトの出力先、フォルダで囲む動作、競合解決
  • フォルダアクセス: フォルダの権限とブックマークを管理する
  • 詳細: ハードウェアアクセラレーション、スレッド数、一時ディレクトリ
  • プライバシー: データ収集の設定
