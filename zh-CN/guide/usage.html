使用指南 ​

打开归档 ​

双击打开 ​

NueZip 会注册为所有受支持归档格式的默认处理程序。只需双击任意归档文件（.zip、.rar、.7z、.tar、.gz、.bz2、.xz、.zst）即可在 NueZip 主窗口中打开它。

使用 NueZip 打开（Finder 上下文菜单） ​

右键点击任意归档文件，并从上下文菜单中选择 使用 NueZip 打开。Finder 扩展还提供快速操作：

  • 解压到此 — 将归档内容解压到当前文件夹
  • 解压到 "文件夹名/" — 解压到指定名称的子文件夹
  • 压缩为 ZIP — 将选中的文件/文件夹压缩为 ZIP 归档
  • 使用 NueZip 打开 — 在主浏览窗口中打开

拖放到托盘 ​

将任意归档文件拖到 NueZip 的菜单栏图标上，即可在放置面板中快速打开它以便即时访问。你也可以将文件拖到托盘图标上以压缩它们。

解压归档 ​

基本解压 ​

  1. 在 NueZip 中打开一个归档
  2. 点击工具栏中的 解压 按钮
  3. 选择目标文件夹
  4. 点击 解压

从 Finder 快速解压 ​

在 Finder 中右键点击归档，并选择以下快速操作之一：

  • 解压到此 — 直接解压到当前文件夹
  • 解压到 "[归档名]/" — 解压到指定名称的子文件夹以保持整洁

带密码解压 ​

对于带密码保护的归档，NueZip 会提示输入密码。内置密码管理器可将凭据安全地存储在你本地的钥匙串中，以便日后使用。

压缩归档 ​

创建新归档 ​

  1. 在 NueZip 主窗口中选择文件或文件夹
  2. 点击工具栏中的 压缩 按钮
  3. 选择归档格式（ZIP、7z、TAR、GZIP 等）
  4. 配置压缩设置（级别、加密方式）
  5. 点击 压缩

从 Finder 压缩 ​

在 Finder 中右键点击文件/文件夹，并选择 使用 NueZip 压缩：

  • 压缩为 ZIP — 快速创建 ZIP 归档
  • 带选项压缩 — 使用高级设置打开 NueZip

通过拖放压缩 ​

将文件拖到 NueZip 菜单栏托盘图标上，即可快速创建 ZIP 归档。

批量操作 ​

批量压缩 ​

  1. 在 NueZip 中选择多个项目
  2. 从工具栏或文件菜单中选择 批量压缩
  3. 每个项目都会被压缩为独立的归档

批量解压 ​

  1. 在 NueZip 中选择多个归档
  2. 从工具栏或文件菜单中选择 批量解压
  3. 所有归档将同时被解压

批量转换 ​

  1. 选择一个或多个归档
  2. 选择 转换 → 选择目标格式
  3. NueZip 会将每个归档重新压缩为所选格式

批量加密 ​

  1. 选择多个 ZIP 归档
  2. 选择 批量加密
  3. 设置密码 — 所有选中的归档都会被加上密码保护

格式转换 ​

在任意支持的格式之间转换归档：

  1. 打开一个归档
  2. 点击工具栏中的 转换
  3. 选择目标格式（例如，RAR → ZIP、7z → TAR.GZ）
  4. 选择输出位置
  5. 点击 转换

归档修复 ​

对于损坏的 RAR 或 ZIP 归档：

  1. 打开损坏的归档
  2. 点击工具栏中的 修复
  3. NueZip 会尝试重建归档数据
  4. 修复后的归档将另存为一个新文件

归档搜索 ​

在归档中查找特定文件：

  1. 点击工具栏中的 搜索 按钮
  2. 输入文件名模式
  3. NueZip 会搜索打开归档中的所有条目
  4. 结果显示完整路径，便于快速导航

性能基准测试 ​

测试你系统的压缩性能：

  1. 前往 工具 → 基准测试
  2. NueZip 会使用各种格式和设置运行压缩测试
  3. 结果展示每种格式的压缩速度（MB/s）和压缩比
  4. 可用此来比较不同压缩方法的性能

多卷（拆分）归档 ​

为大型数据创建拆分归档：

  1. 在压缩过程中，启用 拆分为多卷
  2. 选择卷大小（例如 100 MB、650 MB、4.7 GB，或自定义）
  3. NueZip 会创建带编号的分卷文件（.zip.001、.zip.002 等）
  4. 要解压，请打开第一个分卷文件 — NueZip 会自动加载其余分卷
  • 密码：为加密归档提供密码
  • 包裹进文件夹：如果归档没有单一的根目录，自动创建一个根文件夹
  • 完成后打开：解压完成后在 Finder 中显示解压出的文件
  • 保留损坏的文件：保留错误发生前已解压的文件（用于部分恢复）
  • 更新模式：选择如何处理已有文件（覆盖、跳过、重命名）

批量解压 ​

  1. 前往 工具 → 批量解压
  2. 点击 添加文件... 选择归档文件
  3. 选择目标文件夹
  4. （可选）启用 解压后删除源文件
  5. 点击 开始

创建归档 ​

压缩文件 ​

  1. 点击工具栏中的 压缩 按钮
  2. 选择要压缩的文件（或将其拖放到窗口中）
  3. 选择 归档格式：ZIP、7Z、TAR、GZIP、BZIP2
  4. 配置 压缩方法 和级别
  5. 设置 保存位置 和归档名称
  6. （可选）设置用于加密的 密码
  7. （可选）设置用于多卷归档的 拆分大小
  8. 点击 压缩

向已有归档添加文件 ​

  1. 在 NueZip 中打开一个已有归档
  2. 点击工具栏中的 添加文件
  3. 选择要添加的文件
  4. 点击 添加

批量操作 ​

批量压缩 ​

  1. 前往 工具 → 批量压缩
  2. 点击 选择文件/文件夹... 选择项目
  3. 每个选中的项目都会成为一个独立的归档
  4. 配置输出 格式、保存位置 和文件命名前缀
  5. 点击 开始

批量转换格式 ​

  1. 前往 工具 → 批量转换格式
  2. 点击 添加文件... 选择源归档
  3. 选择 目标格式
  4. （可选）启用 转换后删除源文件
  5. 点击 开始

批量加密 ​

  1. 前往 工具 → 批量加密
  2. 点击 添加文件... 选择归档
  3. 输入 密码
  4. 点击 加密

高级功能 ​

归档修复 ​

修复损坏或损坏的归档：

  1. 选择损坏的归档
  2. 前往 工具 → 修复归档
  3. NueZip 会扫描头部、重建目录并修复数据块
  4. 查看修复结果

格式转换 ​

在格式之间转换归档：

  1. 打开一个归档或选择一个文件
  2. 前往 文件 → 转换格式
  3. 选择目标格式和压缩级别
  4. （可选）删除原始文件
  5. 点击 转换

密码管理器 ​

NueZip 将归档密码安全地存储在你本地的钥匙串中：

  1. 前往 工具 → 密码管理器
  2. 查看所有已保存的密码
  3. 添加、编辑或删除条目
  4. 打开匹配的加密归档时，密码会自动应用

性能基准测试 ​

测试你系统的压缩性能：

  1. 前往 工具 → 性能基准测试
  2. 选择一个测试文件（或使用默认文件）
  3. 点击 测试
  4. 查看结果，包括压缩/解压速度和评级

归档搜索 ​

在归档中查找文件：

  1. 打开一个归档
  2. 按下 Cmd+F 或点击搜索图标
  3. 输入文件名，可选择是否区分大小写或全字匹配
  4. 浏览搜索结果并点击以导航

键盘快捷键 ​

快捷键操作
Cmd+O打开归档
Cmd+N新建归档
Cmd+E解压
Cmd+F在归档中查找
Cmd+,打开设置
Cmd+W关闭窗口
Cmd+Q退出应用
Cmd+↑向上一级
Cmd+→前进

设置 ​

通过 NueZip → 设置 或按下 Cmd+, 访问设置：

  • 通用：语言、登录时启动、外观主题
  • 压缩：默认格式、压缩级别、拆分大小
  • 解压：默认目标、包裹行为、冲突处理
  • 文件夹访问：管理文件夹权限和书签
  • 高级：硬件加速、线程数、临时目录
  • 隐私：数据收集偏好
